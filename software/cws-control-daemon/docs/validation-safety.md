# Validation safety boundary

Validate this software only with an authorized configuration and a destination
owned by the relevant experiment. Keep source records, timing observations,
actuation acknowledgements, fault-injection records, and results outside this
repository.

Start in recommendation mode. Before enabling apply mode, review the complete
external configuration, verify the controller's fail-closed transport and
transaction requirements, and confirm that a separate operator has authorized
the destination. The portable source tree does not establish hardware support,
physical effectiveness, or network-change authorization.

Use synthetic inputs for repository tests. Do not turn unlabelled observations
into claims about people, activity, locations, or service quality.
